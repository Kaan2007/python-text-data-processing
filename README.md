# Python Text & Log Data Processing

A collection of lightweight Python scripts demonstrating file I/O operations, string manipulation, and frequency analysis using core data structures (dictionaries, lists, tuples).

## Included Scripts

* **`top_sender_counter.py`**: Parses mail log files (`mbox-short.txt`) to count user interactions and identify the most frequent sender using hash mapping (dictionaries).
* **`hourly_activity_log.py`**: Extracts timestamps from unstructured headers and generates a sorted distribution of hourly activity.
* **`spam_analyzer.py`**: Filters confidence metrics from log files and computes statistical averages with error-guarded parsing.

## Key Concepts
* File Streams & Exception Handling (`open`, `try/except`)
* String Tokenization & Slicing (`split`, `strip`)
* Data Aggregation & Frequency Histograms (`dict.get()`)
* Tuple Sorting & Data Transformation
